Data & backup
Export history (CSV)
The history as recorded: one row per minute, with that minute's averages — powers in W, battery charge in %. Grid: positive = bought, negative = sold. Battery: positive = discharging, negative = charging. Up to 366 days per file.
Configuration backup
A file with the inverter profiles and connection, timezone, notifications and MQTT (password included: keep the file somewhere safe), to set up this device (or a new one) the same way. Not included: history (export it above), licenses, Wi-Fi and plugin settings.
Reset device
Deletes the history and every setting and goes back to the setup wizard, like a new device. Licenses and Wi-Fi are kept.
